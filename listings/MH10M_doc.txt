      ; MH10M v0.1.0 - MH-10M 47: the Casio MH-10M desk calculator on the C47 / R47
      ; The 10-digit LCD (7-segment digits drawn with AGRAPH, the decimal point and the thousands marks) and
      ; the Casio's keypad drawn on the screen: the key pressed is shown inverted (XOR) until the next key.
      ; It works as the Casio: algebraic entry (no stack), left to right; 10 digits, the results truncated to
      ; what the display shows (as the Casio keeps them: 1 / 3 x 3 = 0.999999999); the constant of = (K: for
      ; x the first number, for + - / the second); % (a x b % = ab/100, a / b % = 100a/b, a + b % = a + ab/100,
      ; a - b % = a - ab/100); MRC (once: recall, twice: clear), M+ and M- (they finish the calculation first);
      ; COST, SELL, MAR (margin on the selling price: two give the third); TAX+ and TAX- with the tax rate
      ; (pressed twice: the tax amount); RATE SET; E: overflow (the display shows the result / 10^10) or
      ; division by 0, only C or AC go on.
      ; After a standby (more than 30 s between two passes of the key wait) the key that wakes it ends the program.
      ; C47 keys: the digits, . and + - x / as they are; ENTER =; +/- +/-; <- (backspace) the Casio's >;
      ; F1-F6 the Casio's top row COST SELL MAR % TAX- TAX+; the second row of the C47 (under the soft keys)
      ; MRC M- M+ C AC RATE-SET; x<>y OFF (the end).
      ; The tax rate and the memory are kept between runs in the global variables MHTAX and MHMEM
      ; (0 STO+ makes them when they are not there).
      ; Screen 400 x 240, row 0 = bottom. ATEXT in GRFNT 21 (the title in GRFNT 10). GRMOD and GRFNT take X.
      ; The user's stack and LASTx are kept (LocR 10: STOS R.00, LASTx in R.08); at the end the display's
      ; value is put in X (the stack lifted, as a calculation) and R20-R91 are cleared (R-CLR 20.72).
      ; Registers: R20 X (the value shown), R21 the first number (ACC), R22 the operation pending (86 + 87 -
      ; 88 x 89 /, 0 none), R23 the constant's operation, R24 the constant K, R25 1 while a number is keyed,
      ; R26 the digits keyed (an integer N), R27 their number, R28 the decimals keyed (-1 no point yet),
      ; R29 1 negative, R30 E (error), R31 the memory, R32 the tax rate, R33 the key, R34 the key before,
      ; R35 the indicators of the key (COST ... RATE), R36 the indicators shown, R37 the tax amount, R38 1 in
      ; RATE SET, R39 COST R40 SELL R41 MAR, R42 the first of two cost/sell/margin keyed (1-3, 0 none),
      ; R43 1 when a number was given since the last operation (keyed or MRC), R44 10^decimals keyed,
      ; R45 the display's digits (N), R46 its decimals, R47 q, R48 the cell k (0 the right), R49 the cells
      ; with a digit (from the right), R50-R59 the digit
      ; shown in each cell (10 blank), R60-R69 the mark shown after each cell (1 point, 2 thousands),
      ; R70-R72 the glyph's words (left, middle, right columns), R73 a counter, R74 work, R75-R78 work,
      ; R79 10^10, R80 the point's word, R81 the thousands mark's word, R82 the clock's JD at the last key wait,
      ; R83 1 / 0 wait on / end (the standby check), R84 the AGRAPH word of LBL :RUN:,
      ; R85 the keys used ("/11/12/.../"), R86 the value of R45 and R46, R87-R89 the key shown inverted (x, row, height 1 or 2 key rows;
      ; 0 none), R90 23 ones, R91 52 ones (the inside of a key).
      ; Indicators (R35, R36): 1 M, 2 minus, 4 E, 8 COST, 16 SELL, 32 MAR, 64 TAX+, 128 TAX-, 256 TAX,
      ; 512 SET, 1024 RATE.
      ; The digits: cell k (0-9, from the right) at x 331 - 31k, 24 columns (4 left, 16 middle, 4 right),
      ; the mark after it at x 356 - 31k (4 columns); AGRAPH words from row 145 (64 rows, GRMOD 1: written
      ; as they are), segments 48 rows high from row 151.
      ; The keypad: key (c, r) (c 0-5 from the left, r 0-4 from the bottom) at x 3 + 66c, row 1 + 29r,
      ; 62 x 25 (the + key 62 x 54, rows 0 and 1).
      ; Labels: LBL 00-10 the glyphs (0-9, 10 blank), LBL 11-85 the keys (their KEY? codes, XEQ IND 33),
      ; LBL 86-89 + - x /, LBL 90-93 the % of each, LBL 94-96 the cost, the selling price, the margin.
